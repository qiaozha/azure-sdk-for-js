# Release History

## 1.0.0-beta.1 (2026-03-10)

### Features Added

- Initial beta release of `@azure/provisioning-storage`.
- `StorageAccount` resource class for `Microsoft.Storage/storageAccounts@2024-01-01`.
- `BlobService` resource class for `Microsoft.Storage/storageAccounts/blobServices@2024-01-01`.
- `BlobContainer` resource class for `Microsoft.Storage/storageAccounts/blobServices/containers@2024-01-01`.
- `QueueService` resource class for `Microsoft.Storage/storageAccounts/queueServices@2024-01-01`.
- `TableService` resource class for `Microsoft.Storage/storageAccounts/tableServices@2024-01-01`.
